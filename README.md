# TraceRCA AI

## Distributed OpenTelemetry Multi-Layer Causal Inference & Auto-Healing Engine

TraceRCA AI is an intelligent observability and root-cause-analysis platform designed for distributed and microservice-based systems.

The system combines:

- OpenTelemetry traces
- Application logs
- Infrastructure metrics
- Service dependency graphs
- Incident and alert correlation
- Temporal dependency analysis
- Causal inference
- Graph RAG
- Evidence-based Root Cause Analysis
- Blast-radius analysis
- Remediation recommendations
- Controlled auto-healing
